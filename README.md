# La mostra capovolta

Percorso web didattico per il concorso «I giovani ricordano la Shoah» (XXV edizione, a.s. 2026/2027), traccia per la scuola secondaria di II grado: «Der Ewige Jude» (1937) e il linguaggio d'odio di oggi.

- Aprire `index.html` con doppio clic: funziona offline, senza server e senza internet.
- Tutti i testi sono in `js/content.js` (cercare `[SCUOLA` e `[DA COMPLETARE`).
- Nessun tracker, nessuna richiesta esterna, nessun pulsante di condivisione. Nessuna immagine di propaganda è riprodotta.
- I messaggi della «Stanza 2027» sono simulazioni didattiche su un gruppo inventato.
